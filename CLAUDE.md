# Mapas mudos: инструкции для Claude Code

Репозиторий с интерактивными контурными картами для школьных уроков географии (школа в Испании). Статические сайты на GitHub Pages, без сборки и без зависимостей.

## Структура
- `index.html`: стартовая страница со списком уроков
- `espana-fisica/`: урок 2, готов (`index.html`, `img/`, `pdf/`)
- `europa-politica/`: урок 3, готов: страны и столицы по списку учителя (51 страна, у 46 — столицы). Собирается из `tools/europa/`: `build_geo.py` (Natural Earth 1:10m, точка зрения Испании: Крым в Украине; Косово из общей версии) → `geo.json`, `build.py` → `index.html`, `mkpdf.py` → `pdf/`. Список — `paises.py`. Подложка 🗺 — лист IGN/CNIG «Mapa político de Europa» 2025, только в «Estudiar». Прогресс в `localStorage`: `mme_eup_`
- `europa-fisica/`: урок 4, готов: всё из листа учителя «Europa física» (157 объектов: берега, реки по бассейнам, озёра, рельеф). Собирается из `tools/europa_fisica/`: `relief.py` (тайлы высот Mapzen/AWS → `img/relief-gray.jpg`, `relief-color.jpg`; цветной — в ступенях и цветах высот листа IGN «Mapa físico de Europa» 2025), `osm_fetch.py` + `osm_compact.py` (заливы, проливы, мысы, Апеннинский п-ов из OpenStreetMap/Nominatim → `osm/`), `regions_dem.py` + `basins.py` (Месета = бассейны Дуэро, Тахо, Гвадианы в Испании; Бетские, Богемия, Великая равнина — по высотам) → `osm/dem_regions.json`, `build_geo.py` (Natural Earth + osm/ → `geo.json`), `build.py`, `mkpdf.py`. Подложка 🗺 — лист IGN/CNIG «Mapa físico de Europa» 2025 (см. `tools/ign/`); в проверках скрыта (на ней названия).jpg`; в проверках скрыта (на ней названия). Список — `datos.py`. Ничего не рисовать «на глаз»: у каждого объекта в «Estudiar» показан источник. Прогресс: `mme_euf_`
- `espana-administrativa/`: урок 1, пока заглушка на стартовой странице
- `historia-tema1/`: история, тема 1, готов. Один файл `index.html` со встроенными данными: события, личности, понятия, исторические границы. Три части по проверочным: p1 германцы и вестготы, p2 Византия, p3 Каролинги
- Тема 1 по истории — большая тема из трёх частей (проверочные): `historia-visigodos/` (часть 1, германцы и вестготы), `historia-bizancio/` (часть 2, Византия), `historia-carolingios/` (часть 3, Каролинги). Тренажёры по 8 шагов от материала до экзамена; собираются одним движком из `tools/historia/`: `python3 build.py <visigodos|bizancio|carolingios> <out.html>`, содержание и карты — в `tools/historia/<тема>.py`, общий шаблон `template.html`, береговая линия Natural Earth 1:10m в `geo.json`. Границы карт Каролингов — `carolingios_geo.json`, собирается `carolingios_geo.py` из GeoJSON Cliopatria. Прогресс в `localStorage`: `h1_vis_`, `h1_biz_`, `h1_car_`
- `historia-recursos/`: PDF для печати без ответов (контурные карты, линия времени, шаблоны тетради и работы); собираются `python3 tools/historia/mkrecursos.py historia-recursos/pdf`
- Тема 2 по истории: `historia-al-andalus/` (аль-Андалус, готов; тот же движок: `python3 build.py al_andalus <out.html>`, содержание `al_andalus.py` по пп. 22–29 резюме учителя, 5 карт из `andalus_geo.json`, который собирает `andalus_geo.py` из Cliopatria + Natural Earth; прогресс `h2_and_`). `historia-islam/` (ислам, пп. 1–21, готов: `python3 build.py islam <out.html>`; своя основа карты `geo_islam.json` из `geo_islam.py` — параметр `GEO` в файле темы; границы `islam_geo.json` из `islam_geo.py`; прогресс `h2_isl_`). Общие функции сглаживания границ — `andalus_geo_util.py`. Подписи областей на картах можно вести по дуге (`klabels` с `{"path": …}`), моря — `seas`
- Сайт открыт для всего класса (испаноязычные ученики): по умолчанию испанский, русский перевод включается переключателем RU. Шпаргалки и готовые ответы к домашним заданиям на сайт не выкладывать — только владельцу в чат
- `tools/ign/ign_warp.py`: листы IGN 2025 (физический и политический, PDF с CNIG; лежат для скачивания в `europa-fisica/pdf/` и `europa-politica/pdf/`) → `img/ign.jpg` уроков 3 и 4; привязка — коническая Ламберта по 32 столицам
- `tools/`: скрипты, исходные данные и шаблон страницы, из которых собран урок 2 (см. `tools/README.md`)

## Правила
- Общение с владельцем только по-русски, коротко и по делу. Действовать самостоятельно, без пошаговых объяснений.
- Адреса уроков не менять: на них уже ссылаются. Новый урок это новая папка рядом с `espana-fisica/`, а на стартовой странице заглушка заменяется ссылкой.
- Страницы статические: никаких серверов, ключей, токенов и приватных данных в репозитории.
- В каждом уроке сохранять строку с источниками данных (OpenStreetMap, Natural Earth, Copernicus DEM, IGN/CNIG, historical-basemaps, Cliopatria, Mapzen Terrain Tiles, Wikimedia Commons для фото). Фото в тренажёрах — только свободные (PD, CC0, CC BY, CC BY-SA), автор и лицензия под каждым фото, список в `tools/historia/fotos.json`.
- Данные historical-basemaps распространяются по GPL-3.0: при выборе лицензии репозитория это учитывать, лицензию без согласования с владельцем не добавлять.
- Тексты для учеников и страницы уроков двуязычные (ru/es), README и tools/README на es/ru/en. При изменениях обновлять все языки; язык хранится в `mme_lang`, общий для стартовой страницы и уроков.
- Прогресс истории хранится в `localStorage` с ключами `h1_` (тема 1) и `h2_` (тема 2).
- Прогресс учеников хранится в `localStorage` браузера, ключи начинаются с `mme_`. Не менять формат ключей без необходимости.

## Обновление из архива
Владелец присылает новый `mapas-mudos.zip`. Распаковать поверх репозитория (`unzip -o`), проверить `git status`, закоммитить с понятным сообщением, `git push`, дождаться публикации Pages и проверить, что страницы уроков отвечают кодом 200.
